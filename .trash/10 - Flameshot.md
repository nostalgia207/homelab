#### 1 - Install

	yay -S flameshot

#### 2 - Usage

	flameshot gui

Opens the selection overlay to manually drag a capture area.

	flameshot full

Captures the entire desktop (all monitors) instantly, no selection needed.

___

#### Keyboard shortcut

Flameshot ships its own default application shortcut for "screenshot" - search "screenshot" in System Settings > Shortcuts to find it directly rather than creating a new Custom Shortcut from scratch (attempting to create a separate custom shortcut caused a conflict).

> [!note]
> Multi-monitor drag-select in flameshot gui only works properly on X11, not Wayland - see `09 - Switching to X11 session.md`.
