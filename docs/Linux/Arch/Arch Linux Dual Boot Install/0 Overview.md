
# Overview

Dual booting alongside an existing Windows 11 install. Two separate disks: Windows on a SATA SSD (sda), Arch on a second NVMe SSD (nvme0n1). UEFI/GPT throughout.

Notes in this folder, in order:

1. Partitioning the second NVMe disk (GPT, UEFI).md
2. Base install (pacstrap, fstab, chroot).md
3. System configuration (locale, hostname, users, keyboard).md
4. GRUB bootloader and custom Windows entry.md
5. NVIDIA driver.md
6. Mounting NTFS drives.md
